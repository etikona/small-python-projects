# Small Python Projects

A curated collection of small Python projects developed for learning, experimentation, and strengthening core programming skills.

This repository contains beginner-to-intermediate level command-line applications that demonstrate fundamental Python concepts such as control flow, modular programming, randomness, and user interaction.

New projects will be added regularly as part of continuous learning.

---

## Repository Structure

```
small-python-projects/
│
├── email_sender/
├── dice_rolling_game/
├── number_guessing_game/
├── rock_paper_scissors/
├── random_number_guess/
├── word_replacement/
├── basic_calculator/
├── email_slicer/
└── README.md
```

Each project is self-contained and can be executed independently.

## Projects

### 1. Email Sender

A simple SMTP-based email sending application written in Python.

**Features**

- Sends emails programmatically
- Custom message support
- Simple configuration

**Topics Covered**

- SMTP protocol
- Python email handling
- User input processing

---

### 2. Dice Rolling Game

A command-line dice rolling simulator that generates random dice values.

**Features**

- Random dice rolls
- Multiple attempts
- Interactive terminal gameplay

**Topics Covered**

- Random number generation
- Loops
- Functions

---

### 3. Number Guessing Game

A classic number guessing game where the player attempts to guess a randomly generated number.

**Features**

- Random target number
- Hint system (higher/lower)
- Unlimited attempts

**Topics Covered**

- Conditional logic
- Loops
- Random module

---

### 4. Rock Paper Scissors

A command-line implementation of the Rock-Paper-Scissors game against the computer.

**Features**

- Player vs Computer
- Random computer choices
- Win/Loss logic

**Topics Covered**

- Lists
- Random module
- Conditional statements

---

### 5. Random Number Guess

A simple program that generates and displays a random number.

**Features**

- Random number generation
- Minimal interface

**Topics Covered**

- Random module
- Basic Python syntax

### 6. Word Replacement

A simple program that replace a word from declared sentence.

**Features**

- declared a sentence
- take user input to that word want to change
- take the user input replaced word

**Topics Covered**

- Python Basic function
- In built replace() function

### 7. Basic Calculator

A simple function to calculate Addition, Subtraction, Multiplication and Division.

**Features**

- Print options to the user
- Ask for values
- Call the functions

**Topics Covered**

- Python Basic function
- Continues While Loop
- In built quit() function
- Concatenation

### 7. Email Slicer

A simple program to slice the email with @ and .

**Features**

- Take user email address
- Slice the user name based on @
- Slice the domain based on . extension

**Topics Covered**

- Python Basic function
- In built split() function
